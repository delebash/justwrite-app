# Keyboard shortcuts

A complete reference. On Mac the modifier is `⌘`; on Windows and Linux it's `Ctrl`.

---

## Global

These work from anywhere in the app.

| Shortcut | Action |
|---|---|
| **Ctrl/⌘ + F** | Open Search and focus the search box |
| **Ctrl/⌘ + Shift + F** | Open project-wide Find & Replace |
| **Ctrl/⌘ + P** | Open the Command Palette |
| **Ctrl/⌘ + J** | Toggle the "Ask the book" chat panel |
| **Ctrl/⌘ + \\** | Toggle the sidebar open / closed |
| **Ctrl/⌘ + Z** | Undo |
| **Ctrl/⌘ + Shift + Z** | Redo |
| **Ctrl + Y** | Redo (Windows alternative) |

Undo and redo are disabled when the focus is inside the rich manuscript editor — the editor has its own undo history (`Ctrl/⌘ + Z` inside the editor undoes typing).

---

## Editor

When the cursor is inside the manuscript editor.

| Shortcut | Action |
|---|---|
| **Ctrl/⌘ + B** | Bold |
| **Ctrl/⌘ + I** | Italic |
| **Ctrl/⌘ + U** | Underline |
| **Ctrl/⌘ + K** | Insert link |
| **Alt + M** | Drop a marker on the selection (or edit the marker at the cursor) |
| **Tab** | Indent paragraph (or sink list item) |
| **Shift + Tab** | Outdent paragraph (or lift list item) |
| **Ctrl/⌘ + Shift + Enter** | Insert new scene boundary (continuous mode) |
| **@** | Open the entity-mention picker |

---

## Read mode (Chapters → Read)

| Shortcut | Action |
|---|---|
| **←** | Previous chapter |
| **→** | Next chapter |
| **Esc** | Exit Read mode and return to Edit |

---

## Search view

When the search input has focus.

| Shortcut | Action |
|---|---|
| **Esc** | Clear the query and any kind filters |

---

## Relations graph

| Shortcut | Action |
|---|---|
| **+** | Zoom in |
| **-** | Zoom out |
| **0** | Reset zoom and pan |
| **Esc** | Clear pinned focus |
